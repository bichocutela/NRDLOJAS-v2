# Fluxo simples de revisão de encarte

Objetivo: reduzir a revisão para um único toque.

1. A descrição já extraída do encarte é enviada para a busca de EAN.
2. Quando há EAN, o app consulta automaticamente o mesmo código na ACP.
3. Se o EAN não existir na ACP, o app busca candidatos pela descrição.
4. O Mestre compara Encarte x ACP e toca em **CONFIRMAR ESTE PRODUTO**.
5. Só depois o vínculo é salvo e a oferta revisada pode aparecer em Consultar Produtos.

Não há cópia/cola obrigatória nem troca manual de filtro no fluxo principal.
